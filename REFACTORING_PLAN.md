## Порядок и проверки

Для изменений правил и ходов обязательны `pnpm test`, `pnpm run type-check` и
`pnpm --filter server run build`. Для изменений корневых Vue-компонентов также
запускать `pnpm run test:browser` (требуется Chromium). Перед завершением
сверить этот список с актуальным состоянием репозитория.
