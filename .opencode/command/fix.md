Исправь баг по описанию пользователя:

$ARGUMENTS

Сначала локализуй путь выполнения и установи причину по коду и имеющимся
тестам. Проверь исправление тестом наблюдаемого поведения. Работай по
инструкциям `AGENTS.md` и применимым инструкциям слоя. Если описание допускает
несколько вариантов с разным игровым поведением, уточни только эту
неоднозначность, продолжая независимую работу.
