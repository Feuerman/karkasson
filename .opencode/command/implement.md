Реализуй задачу:

$ARGUMENTS

Сначала изучи ближайший существующий код и коротко обозначь план, если задача
нетривиальна. Учитывай указанные пользователем цель, ограничения и критерии
готовности; если критерии не заданы, выведи минимальные проверяемые критерии из
описания. Делай минимальный связный diff, следуй AGENTS.md и не добавляй
несвязанный рефакторинг или новые зависимости без необходимости. Сопоставь
поведение с тестами и добавь или обнови проверки пробелов. Для продуктового
изменения обнови CHANGELOG согласно правилам проекта; версию меняй только когда
задача включает подготовку релиза. Запусти проверки, требуемые AGENTS.md для
затронутых областей. В итоговом сообщении укажи сделанное и фактически
запущенные проверки.
