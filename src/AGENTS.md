# Клиентские инструкции для агентов

Дополнение к корневому `AGENTS.md`; здесь только правила клиентского слоя.

## Границы ответственности

- Клиент отображает серверное состояние и отправляет пользовательские
  намерения. Не реализуй на клиенте правила размещения, подсчёт очков,
  допустимость фишек или другие игровые решения.
- Взаимодействие с Socket.IO проходит через `modules/GameService.ts`.
  Слушатели и таймеры удаляй при смене контекста или размонтировании; не
  регистрируй их повторно при каждом обновлении состояния.
- Типы домена импортируй из `@server/*`; типы Socket.IO и UI-специфичные
  состояния размещай в `src/types/`.

## Поведение клиента

- Для поворота сообщай серверу только угол поворота; не отправляй обратно
  целый объект тайла как авторитетное состояние.
- После команды показывай ошибку через `notifyError`/`notificationService` и
  синхронизируй локальное превью с последним серверным состоянием.

## Проверки клиентского слоя

- При изменении клиентского поведения запускай `pnpm run build` в дополнение к
  общим проверкам из корневого `AGENTS.md`.
- Для UI-хелперов используй unit-тесты; транспортное поведение покрывай
  интеграционным тестом `tests/integration/clientGameService.test.ts`.
